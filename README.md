# Đời Mình – Hành Trình

Game web tiếng Việt lấy cảm hứng từ thể loại mô phỏng cuộc đời: sống qua từng ngày, chọn hoạt động, xây dựng quan hệ, theo dõi tuổi và thử nhiều hình thức đầu tư.

## Chơi trên máy

Mở `index.html` trong trình duyệt. Tiến trình lưu trong `localStorage` của trình duyệt hiện tại.

## GitHub Pages

Trang được xuất bản từ `index.html` bằng GitHub Actions. Sau khi workflow chạy thành công, mở **Settings → Pages** để xem URL GitHub Pages của repo.

Mọi khoản lời/lỗ đầu tư trong game đều là mô phỏng, không phải dữ liệu thị trường hoặc tư vấn tài chính.
